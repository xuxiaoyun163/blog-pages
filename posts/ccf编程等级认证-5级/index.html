高精度加法#

思路：

  1. 因为输入的数字很大,我们把数字当作字符串接收
  2. 我们将得到的字符串转换成整型数组，方便利用竖式计算
  3. 在进行竖式计算时，我们是从个位开始计算，所以我将数组反转，从低位开始相加，我们将相加结果放在结果数组中
  4. 我们要获取两个数字中最大的一个数字的长度， 作为相加次数
  5. 在相加的过程中对于大于10的数字我们要进位
  6. 判断最高位是否产生进位，如果产生进位就让我们的长度+1
  7. 输出结果
#include <iostream>
#include <algorithm>    
using namespace std;
int main()
{
        // 获取输入的数字
        string a, b;
        cin >> a >> b;
        int arr[502]={}, brr[502] ={} , res[502] = {} ;

        // 将数字转成数组
        for(int i  = 0 ; i < a.size(); i++){
            arr[i] =  a[i] -'0';
        }

        for(int i = 0; i < b.size(); i++){
            brr[i] = b[i] -'0';
        }

        // 反转数组
        reverse(arr, arr + a.size());
        reverse(brr, brr + b.size());


        // 获取相加最大长度
        int max_len = max(a.size(), b.size());

        // 开始进行加法操作
        for(int i = 0 ;i < max_len; i++){
            // 这里使用+= 因为又能会有下一位给的进位
                res[i] += arr[i] + brr[i];
                // 判断是否要进位
                if(res[i] >=10){
                    res[i]-= 10; // 减去进位
                    res[i+1] = 1;// 进位
                }
        }


        // 判断最高位是否产生进位
        if(res[max_len] != 0){
            max_len++;
        }

        // 反转数组
        reverse(res,res+max_len);


        // 输出结果
        for(int i = 0 ; i < max_len; i++ ){
            cout << res[i];
        }

return 0;
}

高精度减法#

思路：

  1. 使用string类型接收我们的参数

  2. 比较a和b的大小，如果a>b的话我们要交换a,b的值 确保a-b是一个正数，如果发生交换即为负数

  3. 将字符串转换成数字，并反转数组

  4. 开始进行减法操作，判断是否需要借位

  5. 反转结果数组，去掉前导0

  6. 输出结果

int main()
{
    string a ,b;
    cin >> a >> b;
    int flag = 1;// 符号
    // 先将数组初始化成0
    int arr[10090]={}, brr[10090]= {} , res[10090] ={};
    // 比较数字大小,确保a-b
    if(a.size() < b.size() || (a.size()==b.size() && a<b)){
        swap(a,b);
        flag = -1;  
    }



    // 将字符串转成数字数组
    for(int i = 0 ; i< a.size() ; i++){
        arr[i]= a[i]-'0';
    }

    for(int i = 0 ; i < b.size() ; i++){
        brr[i]= b[i]-'0';
    }

    // 反转数组
    reverse(arr, arr+a.size());
    reverse(brr, brr+b.size());


    //开始进行减法
    for(int i = 0; i < a.size(); i++){
        res[i] = arr[i] - brr[i];
        // 判断是否要进位
        if(res[i] <0 ){
            res[i] += 10;
            arr[i+1]--; // 借位
        }
    }



    // 输出结果
    // 判断是否是负数
    if(flag== -1){
        cout << '-';
    }
    // 反转
    reverse(res, res+a.size());

    // 找到第一个非0的数字的下标
    int index = 0;
    while (index < a.size() - 1 && res[index] == 0) {
        index++;
    }


    for(int i = index; i < a.size(); i++){
        cout << res[i];
    }

return 0;
}

辗转相除法(欧几里得算法)#

基础概念#

辗转相除法，又称欧几里得算法（Euclidean Algorithm），是用来求两个正整数最大公约数（Greatest Common Divisor, GCD）的一种高效算法。

数学原理#

如果 a = b × q + r（其中 q 是商，r 是余数，0 ≤ r < b），那么：

gcd(a, b) = gcd(b, r)

当r = 0 时 b 为最大公约数

代码实现#

int gcd(int a , int b ){
    int r = a % b;
    while(r !=0){
        a = b;
        b = r;
        r = a % b;
    }
    return b;
}

int main()
{
    cout << gcd(48,18);
return 0;
}

最小公倍数#

基本概念#

最小公倍数是指两个或多个整数公有的倍数中最小的一个正整数。

数学表达#

对于两个正整数a和b

LCM(a,b) = min{m | m是a的倍数 且 m是b的倍数 且 m > 0}

实现方法-枚举法#

思路 遍历找出一个数字既可以整除a 也可以整除b

int lcm_by_enumeration(int a, int b) {
    int max_val = (a > b) ? a : b;
    while (1) {
        if (max_val % a == 0 && max_val % b == 0) {
            return max_val;
        }
        max_val++;
    }
}

实现方法2-利用最大公约数(重点)#

LCM(a,b) = (a × b) / GCD(a,b)

// 求最大公约数（辗转相除法）
int gcd(int a, int b) {
    while (b != 0) {
        int r = a % b;
        a = b;
        b = r;
    }
    return a;
}

// 求最小公倍数
int lcm(int a, int b) {
    return a / gcd(a, b) * b;  // 先除后乘避免溢出
}

int main() {
    int a, b;
    cout << "请输入两个正整数: ";
    cin >> a >> b;

    cout << "最大公约数: " << gcd(a, b) << endl;
    cout << "最小公倍数: " << lcm(a, b) << endl;

    return 0;
}

对于多个数的最小公倍数#

LCM(a,b,c) = LCM(LCM(a,b), c)

LCM(a,b,c,d) = LCM(LCM(LCM(a,b), c), d)

// 求n个数的最小公倍数
int lcm_of_n(int arr[], int n) {
    int result = arr[0];
    for (int i = 1; i < n; i++) {
        result = lcm(result, arr[i]);
    }
    return result;
}

素数表的埃氏筛法和线性筛法#

素数的概念#

定义： 一个大于1的自然数，除了1和它本身之外不再有其它因数的数成为素数

试除法#

bool isPrime(int n){
    if(n < 2){
        return false;
    }
    for(int i = 2; i * i < n;i++){
        if(n % i ==0){
            return false;
        }
    }
    return true;    
}

埃氏筛法#

核心思想#

素数的数倍是合数

 bool isPrime(int n){
    // 数组标记，默认所有的数字都是素数
    vector<bool> prime(n+1,true); 
    for(int i = 2; i < n;i++){
        if(prime[i]){// 如果这个数字是素数，我们就将他的倍数全部改成false
            for(int j =i+i; j <=n; j+=i){
                prime[j] = false;
            }
        }
    }
    return prime[n];
}

线性筛法#

在埃氏筛中很多的数字会重复的被2和3进行标记，例如12就会先被2标记一次，然后又会被3标记一次，为了解决这样的问题，我们利用唯一分解定理 将合数 分解为最小质数 ✖另一个数，找出所有的合数

唯一分解定理#

定义#

唯一分解定理（Unique Factorization Theorem），也称为算术基本定理（Fundamental Theorem of Arithmetic），表述为：任何一个大于1的正整数都可以唯一地分解为质数的乘积形式。

对于任意整数 $n > 1$，存在唯一的质数序列 $p_1 \leq p_2 \leq \cdots \leq p_k$ 和正整数序列 $e_1, e_2, \ldots, e_k$，使得：

$$n = p_1^{e_1} \cdot p_2^{e_2} \cdots p_k^{e_k} = \prod_{i=1}^k p_i^{e_i}$$

其中每个 $p_i$ 都是质数。

实例#

  • $12 = 2^2 \times 3^1$
  • $60 = 2^2 \times 3^1 \times 5^1$
  • $97$（本身就是质数）$= 97^1$

特性#

  1. 存在性：每个大于1的整数都能表示为质数乘积
  2. 唯一性：这种分解方式是唯一的（不考虑因子顺序）
  3. 质因子：分解结果中的每个因子都是质数

代码实现#

int main()
{

 int n ,p = 2; // 作为试除数 从2开始
 cin >> n;

 while(n != 1){ // 当n不等于1的时候要一直对n进行分解

    // 如果n能被p整除 我就一直把p除尽
    while(n%p==0){
           cout << p << endl;
           n = n/p; 
    }
    // 如果不能整除p，就让p+1 继续试
    p++;
 }

    return 0;
}

二分查找/二分答案（也称二分枚举法）#

二分查找#

定义#

二分查找（Binary Search）是一种在有序数组中查找特定元素的高效搜索算法。它通过不断将搜索区间减半来快速定位目标元素。

基本原理#

在有序数组中，通过比较中间元素与目标值的大小关系，可以确定目标元素在左半部分还是右半部分，然后在相应的半部分继续查找，直到找到目标元素或搜索区间为空。

算法步骤#

  1. 设定左边界 left 和右边界 right
  2. 计算中间位置 mid = (left + right) / 2
  3. 比较 arr[mid] 与目标值：
    • 如果相等，找到目标，返回索引
    • 如果 arr[mid] > target，在左半部分查找
    • 如果 arr[mid] < target，在右半部分查找
  4. 重复步骤2-3，直到找到目标或搜索区间为空

代码实现1(查找确切的值)#

int main()
{
    int n ,target;
    cin>> n >> target;

    int arr[100];
    for(int i = 0; i < n; i++  ){
        cin >> arr[i];
    }
    // 一定要确保数据是有序的
    sort(arr, arr+n);

    int left = 0;   
    int right = n - 1;  



    while(left <= right){
       // int mid = (left+right) / 2 ; // 先相加有可能会溢出，超出int范围
     int  mid = left + (right - left) / 2;// 这样取中间值可以规避溢出的问题

        if(target ==  arr[mid]){
            cout << mid << endl;
            break;
        }else if(target < arr[mid]){
            right = mid - 1;
        }else{  
            left = mid + 1;
        }

    }

return 0;
}

二分答案#

定义#

二分答案（Binary Search on Answer）是一种算法技巧，用于在答案具有单调性的情况下，通过二分搜索来寻找最优解的方法。

核心思想#

不是直接计算答案，而是猜测答案，然后验证这个猜测是否可行。利用问题的单调性质，通过二分搜索快速找到最优解。

使用条件#

  1. 答案具有单调性：如果某个答案可行，那么比它更优（更大或更小）的答案也可能可行
  2. 可以有效验证：给定一个候选答案，能够在合理时间内判断它是否可行
  3. 答案有界：存在明确的上下界

贪心算法#

定义#

贪心算法（Greedy Algorithm）是一种在每一步选择中都采取在当前状态下最好或最优（即最有利）的选择，从而希望导致结果是最好或最优的算法策略。

核心思想#

  • 局部最优选择：在每个决策点做出当前看起来最好的选择
  • 无后效性：一旦做出选择，就不会改变
  • 最优子结构：问题的最优解包含子问题的最优解

分治算法（归并排序和快速排序）#

定义#

分治（Divide and Conquer）是一种重要的算法设计思想，它将一个复杂的问题分解为若干个规模较小的相同子问题，递归地解决这些子问题，然后将子问题的解合并得到原问题的解。

核心特征#

  1. 分解（Divide）：将问题划分为更小的子问题
  2. 解决（Conquer）：解决子问题
  3. 合并（Combine）：将子问题的解组合成原问题的解

归并排序#

定义#

归并排序（Merge Sort）是一种基于分治思想的稳定排序算法。它将待排序数组递归地分解为更小的子数组，直到每个子数组只有一个元素，然后将这些子数组逐层合并，最终得到有序数组。

工作流程#

[38, 27, 43, 3, 9, 82, 10] /
[38, 27, 43, 3] [9, 82, 10] / \ /
[38, 27] [43, 3] [9, 82] [10] / \ / \ / \ | [38][27] [43][3] [9][82] [10]

代码实现#

#include <iostream>
using namespace std;
int arr[101] ;

// 进行合并操作
void merge(int arr[101] , int l , int mid , int r){
    int n1 = mid - l +1; // 左区间长度
    int n2 = r - mid; // 右区间长度
    int L[n1] , R[n2];
    for(int i = 0; i < n1; i++){
        L[i] = arr[l + i];
    }
    for(int j = 0 ; j <n2 ; j++){
        R[j] = arr[mid + j +1];
    }

    // 合并两个数组
    // i指向第一个数组 j指向第二个数组 k指向结果数组
    int i = 0, j = 0, k = l;
    while(i<n1 && j < n2){
        if(L[i] <= R[j]){
            arr[k] = L[i];
            k++;
            i++;
        }else{
            arr[k] = R[j];
            k++;
            j++;
        }
    }
    // 如果还有剩余的元素，一次性全部放入到arr中
    while(i < n1){
        arr[k] = L[i];
        k++;
        i++;
    }

    while(j < n2){
        arr[k] = R[j];
        k++;
        j++;
    }


}

void mergeSort(int arr[101] ,int l , int r ){

    if(l < r){
    int mid = l + (r-l)/2;

     mergeSort(arr,l ,mid); // 左区间
     mergeSort(arr,mid+1,r);// 右区间

     // 排序合并
    merge(arr , l , mid , r);
    }
}


int main()
{
    int n;
    cin >> n;
    for(int i = 0; i < n; i++) cin >> arr[i];

    // 归并排序
    mergeSort(arr,0,n-1);

    for(int i = 0; i < n; i++){
        cout << arr[i] << " ";
    }

    return 0;

}
