布尔型#

bool 关键字用来申明一个bool变量

bool b = true

bool类型的表示范围只有2中 真与假，在c++ 中我们把真定义为关键字true 把假定义为关键字false

严格来说bool也是属于整数大类，如果我们输出布尔值的变量可以发现结果就是0和1

bool var_b1 = true;
bool var_b2 = false;
cout << var_b1 << endl; // 1
cout << var_b2 << endl; // 0

所以在给一个bool类型赋值时，我们可以使用0和1代表真和假

bool var_b1 = 1; // true
bool var_b2 = 0; // false

c++ 与 c 语言在格式化输出时的对比

我们输出两个变量的和

int a =10;
int b =20;
printf("%d + %d = %d、" , a , b , a+b);

其实我们可以把printf的第一个参数当作一个模板，%d就是占位符,我们使用后面的变量对%d进行替换

int a =10;
int b =20;
cout << a << "+" <<  b << "=" << a+b;

我们发现在格式化一个字符串输出的时候，其实c语言的printf是更加高效的，而c++的cout没有高效的格式字符串的能力

在c++20中增加了一个新能力format完全可以成为printf的上位替代

#include<format>
int a =10;
int b =20;
cout << format("{} + {} = {}" , a, b , a+b) << endl;

format中的第一个参数代表我们要格式化输出的模板，我们使用{}当作占位符

如果我们在vscode中使用format发生错误时，其实当前我们使用的c++ 插件的编译环境比较，我们需要对进行一些设置

我们打开设置，在设置中找到c++插件，并编译时使用的c++版本改成gun++20即可

逻辑与&&

a && b 如果a为false 那么这个与运算一定是false 所以 b 就不会执行

逻辑或||

true || true → true

true || false→ true

false || false→ false

逻辑非 !

!true -> false

!false -> true

去重#

方法1 ：纯手搓

注意： vector删除元素之后 长度会发生变化

  vector<int> v = {1,1,2,2,3,3,4,4};
    for(int i = 0; i < v.size(); i++){
        for(int j = i+1; j < (int)v.size()){
            if(v[i] == v[j] ){
            // 删除重复元素
            v.erase(v.begin()+j);
            }else{
                j++;
            }
        }
    }

方法2 ：unique + earse

unique: 它的作用是移除连续重复的元素，但并不真正从容器中删除元素，而是将重复的元素移到序列的末尾，并返回指向第一个重复元素位置的迭代器。

vector<int> v = {1, 1, 2, 2, 3, 3, 4, 4};

// 方法1：两步完成
sort(v.begin(), v.end());           // 先排序
auto it = unique(v.begin(), v.end()); // 再去重
v.erase(it, v.end());               // 真正删除

// 方法2：一行完成
sort(v.begin(), v.end());
v.erase(unique(v.begin(), v.end()), v.end());
  • unique 要求元素已经排序或者局部有序才能有效去重
  • 如果不排序直接使用 unique，只会去除相邻的重复元素
vector<int> v = {1, 2, 1, 3, 2};  // 未排序
// unique 后变成 {1, 2, 1, 3, 2} - 没有变化，因为没有相邻重复元素

方法3 ： 直接使用set集合去重


int main(){
    vector<int> v = {1,1,2,2,3,3,4,4};
    
    // 使用set自动去重
    set<int> s(v.begin(), v.end());
    
    // 转回vector
    v.assign(s.begin(), s.end());
    
    for(auto x: v){
        cout << x << " ";
    }
    return 0;
}
