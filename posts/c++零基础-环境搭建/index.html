我们这里使用的GCC

我们通过msys2安装c++的编辑器gcc，通过gcc去编辑C++ 文件

点击下面官网链接进入官网

MSYS2

在官网中找到安装包并下载

因为访问官方需要科学手段，如果不能科学上网的同学可以使用国内镜像网站进行安装

这里提供阿里的镜像网站，我们打开网站点击第一个

https://mirrors.aliyun.com/msys2/

找到最新版的安装包进行下载

下载完成之后我们开始安装

这个最好就是默认c盘，为了避免不必要的麻烦，接下来一直点击next就可以

安装完成之后我需要在开始菜单中找到msys2 ucrt64 打开

将官网中的这一条命令写入进去，开始g++的下载

$ pacman -S mingw-w64-ucrt-x86_64-gcc

这个直接输入Y

然后开始下载我们的依赖

因为pacman 命令下载的依赖来自有国外的仓库，所有下载很慢，有可能出现下载失败的情况，如果出现了网络错误或者下载失败，我们需要配置 pacman 使用国内镜像源的仓库进行下载

  • 找到msys2安装目录默认是在c盘 C:\msys64

  • 打开C:\msys64\etc\pacman.d 目录

  • 编辑 /etc/pacman.d/mirrorlist.mingw32 ，在文件开头添加：

Server = https://mirrors.aliyun.com/msys2/mingw/i686
  • 编辑 /etc/pacman.d/mirrorlist.mingw64 ，在文件开头添加
Server = https://mirrors.aliyun.com/msys2/mingw/x86_64
  • 编辑 /etc/pacman.d/mirrorlist.msys ，在文件开头添加
Server = https://mirrors.aliyun.com/msys2/msys/$arch
  • 编辑 /etc/pacman.d/mirrorlist.ucrt64 ，在文件开头添加
Server = https://mirrors.aliyun.com/msys2/mingw/ucrt64

这里举一个栗子！每一个都要配置

然后执行 pacman -Sy 刷新软件包数据即可。

安装完成之后我们打开C:\msys64\ucrt64\bin

这里已经下载好我们需要的g++编辑器了，为了方便使用我们还需要将当前目录配置到系统环境变量中

  • 在搜索框中搜索编辑系统环境变量

然后点击环境变量

然后在path中 编辑将我们的文件路径添加进去

然后我们测试是否配置成功win + R 输入cmd 在cmd中输入

g++ --version

配置编辑器#

在扩展中安装c/c++ 插件

我们在任意一个地方创建一个文件夹 名字叫c++ 当然这个名字是可以任意取一个

我们使用vs打开这个文件夹

我们右键新建一个文件，名字叫demo.cpp，并写入一些初始代码

#include <iostream>
using namespace std;

int main() {
    cout << "Hello World!" << endl;
    return 0;
}

如果我们这里头文件有红色波浪线那是因为c++ 插件没有找到合适的编译器，我们可以按住  ctrl+shitf+p 输入select intelliSense配置

我们选择我们下载的g++ 进行编译

我们点击新建终端，然后在右下角选择powershell 类型的终端

我们输入c++ -version查看c++ 编译器的版本，如果这个报错找不到c++ 那我们就需要以管理员的方式重新打开vscode

我们在powerShll中输入c++ demo.cpp -o demo -O2 --std=c++11 -Wall对指定的文件进行编译，并且生成指定的demo.exe 我们运行当前的demo，可以看到我们的输出的结果为hello world 当然我们这里也可以使用g++ 也是同样的效果

关于c++ 指令中的一些参数

  • c++ 编译器 同g++ 一样的效果

  • source.cpp 待编译的cpp源文件

  • -o 指定输出文件名称

  • -O2 二级优化

  • –std=C++11 使用c++ 11 标准进行编译

  • -Wall 输出所有 warining

如果每次编译和运行都需要使用指令会很麻烦，我们可以编写一个shell脚本自动帮我们进行编译和运行

我们在c盘的根目录下新建一个文件夹Script在文件夹中创建cr.ps1内容如下

param(
  [string]$fileName,
  [string]$inputFileName,
  [string]$outputFileName
)
# 切换为 utf8
# [Console]::OutputEncoding = [System.Text.Encoding]::UTF8

function Write-Log {
  param (
    [string]$Message,
    [System.ConsoleColor]$Color = [System.ConsoleColor]::Red
  )
  Write-Host "====== $Message ======" -ForegroundColor $Color
}

# 检查 cr 指令后是否跟着文件名
if (-not $fileName) {
  Write-Log "请在 cr 指令后跟上文件名，如 test.cpp"
  exit 1
}

# 删除 .cpp 后缀
if ($fileName.EndsWith(".cpp")) {
  $fileName = $filename -replace "\.cpp$", ""
}

# 检查cpp文件是否存在
if (-not (Test-Path "$fileName.cpp")) {
  Write-Log "未找到 $fileName.cpp，请查看 VSCode 左侧的资源管理器是否有该程序"
  exit 1
}

$gccOutput = c++ "$fileName.cpp" -o "$fileName.exe" -O2 --std=c++20 -Wall -DDEBUG `
                 -fexec-charset=GBK `
                 -fdiagnostics-color=always 2>&1
$exitCode = $LASTEXITCODE
$gccOutput | ForEach-Object { Write-Host $_ }
if ($exitCode -ne 0) {
  if ($gccOutput -match "C:\\Users") {
    Write-Log "用户名不能为中文，请根据说明文件指引进行修改"
    exit 1
  }
  if ($gccOutput -match "WinMain") {
    Write-Log "程序中没有 main 函数，请检查是否保存"
    exit 1
  }
  Write-Log "编译失败，请检查上述语法错误信息后进行修改"
  exit 1
}

if ($gccOutput -match "warning:") {
  Write-Log "上述是警告信息，请检查（如在预期内则可忽略）" Yellow
}
Write-Log "编译成功，开始执行(按 CTRL+c 可强制终止正在执行的程序)" Green

if ($inputFileName) {
  if (-not(Test-Path $inputFileName)) {
    Write-Log "未找到输入文件 $inputFileName，请查看 VSCode 左侧的资源管理器是否有该文件"
    exit 1
  }
  if ($outputFileName) {
    Get-Content $inputFileName | & "./$fileName.exe" | Out-File "./$outputFileName"
  } else {
    Get-Content $inputFileName | & "./$fileName.exe"
  }
} else {
  & "./$fileName.exe"
}
$exitCode = $LASTEXITCODE
if ($exitCode -ne 0) {
  Write-Log "运行错误，可能存在数组越界、除 0、野指针、栈溢出、爆内存等问题" Red
  exit 1
}
Write-Log "执行结束，删除可执行程序" Green

Remove-Item "./$fileName.exe"

简洁版

param([string]$f, [string]$i)
c++ "$f.cpp" -o "$f.exe" -O2 --std=c++20 -DDEBUG
if ($i) {
  Get-Content $i | & "./$f.exe"
} else {
  & "./$f.exe"
}

然后我们将C:\Script 配置到系统环境变量中

window 默认不容许我们运行自动的shell，所有我们要先解除限制

  • 以管理员权限启动powerShell

  • 输入Set-ExecutionPolicy RemoteSigned

  • 输入Y 确认

然后我就可以在vscode中使用cr 脚本了
