动态规划#

定义#

动态规划是一种用于求解具有最优子结构和重叠子问题特性的复杂问题的算法设计范式。它通过把原问题分解为相互关联的子问题，记录并复用子问题的解，从而避免重复计算，大幅提升效率
最优子结构：原问题的最优解能够由其子问题的最优解组合而成。
重叠子问题：在求解过程中，完全相同的子问题会被反复计算多次，动态规划通过“记忆化”消除这种冗余。

[!NOTE] 求阶乘问题： 思考求阶乘问题是否满足动态规划呢？

int f(int n ){
    if(n == 1) return 1;
    return n*f(n-1);
}

我们可以使用动态规划来优化当前过程，该怎么优化呢？

动态规划是如何解决重复子问题

实现#

核心思想：用一个表格（数组、矩阵等）存储已解决的子问题答案，在需要时直接查表获取，不重新求解。

自顶向下（记忆化搜索）#

从原问题出发递归求解，发现子问题已计算过则直接返回结果。

自底向上（递推/表格法）#

先解决所有最小子问题，再逐步向上组合出原问题的解。
