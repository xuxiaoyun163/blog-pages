配置markdown编写环境#

解决的问题： 在使用vscode编写markdown文件时，我们使用的换行在markdown文件被渲染时，不会被换行，因为在markdown中2个空格表示换行
解决方法：
自定义快捷键，配置shift+enter每次换行默认在后面加上2个空格

  1. Ctrl+K Ctrl+S 打开快捷键面板
  2. 点右上角 Open Keyboard Shortcuts (JSON)，打开 keybindings.json
  3. 粘贴下面配置：
[
    {
        "key": "shift+enter",
        "command": "editor.action.insertSnippet",
        "args": {
            "snippet": "  \n"
        },
        "when": "editorLangId == markdown && !editorHasSelection"
    }
]

配置settings.json（防止保存删掉空格）

  1. 快捷键ctrl+,打开设置
  2. 搜索setting.json在里面配置下面内容
{
    "[markdown]": {
        "files.trimTrailingWhitespace": false
    },
    "editor.renderWhitespace": "boundary"
}
  • files.trimTrailingWhitespace：md 文件保存不删除行尾空格（最重要）
  • editor.renderWhitespace：可视化显示空格，方便你看到那两个空格
