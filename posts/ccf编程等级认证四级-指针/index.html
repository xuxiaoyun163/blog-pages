指针与地址的概念#

在讲解指针之前我们需要明白，变量到底是怎么存储在计算中的呢？

其实一个整数存储在计算机的过程，类似我们的在菜鸟驿站存一个商品

我们在内存中会有一片连续的内存空间（快递柜），每一个空间都有唯一的一个下标（快递柜编号），计算机会随机挑选一个空的内存，将数字存放在里面（快递员将包裹存入指定的快递柜中）

例如下面这段代码，在内存中其实是放在指定的下标的柜子中

int main(){
    int a ;  // 找到一个空的柜子
    a =100;  // 将100 放入到柜子中
    return 0;
}

我们可以根据柜子的编号将柜子中的物品拿走，对应的代码就是我们可以根据变量名a

获取内存中存放的值。

现在突然有一天你需要陪你女朋友，没时间去拿快递，你希望隔壁老王去帮你拿一下，那你需要告诉老王快递柜的编号

在计算中，如果我们也需要进行这种操作，将快递柜的编号告诉别人怎么办呢？

其实有的人就会认为，这个100 不就是a嘛，我直接将a告诉它不就行了。

但是在计算中，我们的地址并不会像快递编号那样，比较简单，计算机中的内存编号非常复杂，而且很长，为了方便我们每次存放和取出我们需要的值，在存放值的过程中呢，我们会将这个编号复制一份给变量名a但是这不是真正的编号，那我们该怎么去获取到当前这个变量的地址呢？

取地址 &

int main(){

    int a = 10;
    &a; // 获取当前真正存放10的地址
    cout << &a; //0xaaf69ffb9c
    return 0;
}

我们知道地址其实一个非常长的编号&a的值可能是0x66666666但是不管这个值有多长，它始终是一个常量就是一个存在的值

现在我们拿到这个值，也就是地址，那我现在想保存这个地址该怎么办呢？

指针 c++ 中的一种数据类型，用于存放地址

int main(){
    int a = 10;
    int *p = &a; // 通过指针存储我们获取到的地址    
    cout << p; //0xaaf69ffb9c
}

那现在我知道了存储的地址之后我该如何去取出这个地址中的内容呢？

解引用 获取当前指针指向地址中的值

int main(){
    int a = 10; // 定义一个变量   
    int* p = &a;// 获取变量的地址，并使用指针p存储
    cout << *p ; //解引用，获取地址中的值 10 
}

指针的经典应用

通过函数交换两个数字的值

void my_swap(int a , int b ){
          int t = a;
              a = b;
              b = t;

}
int main(){
    int a = 10; 
    int b  = 20;
    my_swap(a,b);    // 值传递，并没有修改
cout << a << " " << b; //10 20
    return 0;
}

void my_swap(int * a , int * b ){ // 我希望把地址穿过来，所以我使用指针去接收
              // 这里的a 和 b 是地址
                int t = *a; // 取出a地址中的地址          
                *a = *b; // 将a地址中的值 赋值为b地址中的值
                *b = t;   // 将b地址中的值赋值为t 

}
int main(){
    int a; 
    int b ;
    my_swap(a,b);    // 值传递，并没有修改
cout << a << " " << b;
    return 0;
}

一维数组与指针#

int main (){
    int arr[] = {1,2,3,4,5};
    cout << arr;
}

在一开始学习数组的时候呢，我们常常会直接coutarr 我们会认为它会输出数组的内容，但其实我们直接输出的数组名 是我们的数组中第一个元素的地址

int main(){
    int arr[] = {1,2,3,4,5};
    cout << arr; //  0x52819ffcb0    
    cout << &arr[0]; // 0x52819ffcb0
    return 0;
}

那我们通过arr获取到第一个元素的地址到底有什么用呢？

int main(){
    int arr[] = {1,2,3,4,5};
    int *p = arr;// 使用指针接收我们的地址
    p++; // 让指针进行运算
    cout <<  * p; //2
    return 0;
}

我知道可以通过指针运算将指针在数组中不断的移动，我们也可以通过指针的方式遍历数组

int main() {

 int arr[] = {1,2,3,4,5};

  int * p = arr;
  for(int i =0 ; i < 5; i++){
    cout << *p << endl;
    p++;
  }
}

我们知道指针可以运算，那指针的运算规则是什么呢？

p+n == p(当前地址) + n * sizeof(p指向的类型)

sizeof 获取当前数据类型或对象的大小 （单位字节）

int main() {

  int arr[] = {1,2,3,4,5};

  int *p = arr;
  cout << p << endl; //0xeed53ffc40
  p++;
  cout << p << endl; //0x162bfffc44
  p++;
  cout << p << endl; //0x162bfffc48
  p++;
  cout << p << endl; //0x162bfffc4c
  p++;
  cout << p << endl; //0x162bfffc50
}

说白了，我们指针的+n 或 -n 操作都是在原来的基础上 增加n 个数据类型的长度

我们可以看一下，下面这段程序会输出什么呢？

int main() {
  int a[] = {1,2,3};
  char s[] = "hello world c++";

  cout << s[sizeof(a)] << endl;
}

一维数组与函数参数#

如果我们需要将一个一维数组作为一个参数传递时，我们该怎样去传递呢？

int max_ele_arr(int arr[],int n){
    int max = 0;
    for(int i = 0 ; i<n ; i++){
      if(arr[i] > max){
        max = arr[i];
      }
    }
    return max;
}


int main(){

     int arr[10]  = {1,2,3,4,5};

     cout << max_ele_arr(arr,5);


}

在这里我们需要明白我们传入的arr到底是什么呢？

 arr 其实是一个地址，那我们该怎么去接收一个地址呢？

我们应该使用指针去接收一个地址

所以int arr[] == int * arr 就是一个指针

int max_ele_arr(int* arr,int n){
    int max = 0;
    for(int i = 0 ; i<n ; i++){
      if(arr[i] > max){
        max = arr[i];
      }
    }
    return max;
}

int main(){

  int arr[10]  = {1,2,3,4,5};
  cout << max_ele_arr(arr,5);


}

我们这么去写也是完全没有问题的！

int main(){

二维数组和指针#

二维数组的定义#

int main(){
    int arr[3][4] = {1,2,3,4};
    int arr[][3] = {1,2,3,4}; // 二维数组在初始化时 一定要有列 可以没有行
    return 0;
}

指针#

int main(){

  int arr[][3] = {1,2,3,4}; // 2 3
  cout << arr << endl; // 0xabfedffca0
  cout << arr[0] << endl;// 0xabfedffca0
  cout << arr[0][0] << endl; // 1
  cout << &arr[0][0] << endl;//0xabfedffca0
  cout << arr+1 << endl ;  // 0xabfedffcac
  cout << &arr[0][0] + 1 << endl; // 0xabfedffca4
}

我们看上述这段代码，在二维数组中我们发现arr arr[0] &arr[0][0] 这三个地址的值是相同的，但是为什么对arr + 1 和 &arr[0][0] + 1 得到的地址会不相同呢？

其实我们要好好理解下面两句话

  • 数组名指向数组中第一个元素的下标

  • p+n == p(当前地址) + n * sizeof(p指向的类型)

在二维数组中，数组的第一个元素其实是一个一维数组

根据p+n的定义来说，我们sizeof(p指向的类型) 等价于 sizeof(一维数组)也就是 sizeof(3 *4)

所以说我们每次进行算数运算时，指针会跳到下一行

而我们的指针指向的是&arr[0][0] 那么我们的p+n 中的sizeof(int) 也就是sizeof(4) 只会跳一个整形的大小

二维数组和参数传递#

在函数中，我们如何正确的传递一个二维数组呢？

还是以找到一个二维数组中的最大值为例子

第一种完全指定行和列

int max_ele_arr(int arr[2][3]){
    int max_ele = 0;
    for(int i =0 ; i < 2; i++){
      for(int j = 0 ; j< 3;j++){
          max_ele =max(max_ele,arr[i][j]);           
      }
    }

    return max_ele;
}

int main(){

  int arr[][3] = {1,2,3,4,5}; // 2 3

  cout << max_ele_arr(arr);


}

第二种只指定列

int max_ele_arr(int arr[][3]){
    int max_ele = 0;
    for(int i =0 ; i < 2; i++){
      for(int j = 0 ; j< 3;j++){
          max_ele =max(max_ele,arr[i][j]);           
      }
    }

    return max_ele;
}

int main(){

  int arr[][3] = {1,2,3,4,5}; // 2 3

  cout << max_ele_arr(arr);


}

使用指针

int max_ele_arr(int (*arr)[3]){
    int max_ele = 0;
    for(int i =0 ; i < 2; i++){
      for(int j = 0 ; j< 3;j++){
          max_ele =max(max_ele,arr[i][j]);           
      }
    }

    return max_ele;
}

int main(){

  int arr[][3] = {1,2,3,4,5}; // 2 3

  cout << max_ele_arr(arr);


}

在前面我知道在一维数组中传递参数时int arr[] == int * arr 我们可以将二维数组中的一维部分替换成指针 int arr[][4] == int (*arr)[4]

指向已经分配好的地址

int main{

 return 0;

指向空地址

int main(){
    
 int *p = NULL;
 int *p = nullptr;

分配一个地址

int main(){
      int *p = new int;  // new 数据类型
      delete p;  // 自己开辟的一个空间一定要记得释放  
    return 0;
}

int main(){
    int *p = (int *)malloc(sizeof(int));

    free(p);// 我们自己申请的空间都是需要手动释放的
}

结构体和指针#

struct Student{
  int id;
  string name;
  int age;
};

int main(){
  // 是让系统帮我分配内存空间
    struct Student s1 = {1 , "zhangsan" , 20};
    cout << &s1 << endl;  //0xbc90bffd80
    cout << &s1.id << endl; // 0xbc90bffd80
}

我们可以发现 结构体名字 指向的地址其实就是结构体中第一个元素的地址


struct Student{
  int id;
  string name;
  int age;
};

int main(){
   // 我们也可以自己分配内存使用malloc 或者new 都可以
   // new 申请了一个内存， 所以我们需要指针去接收
    struct Student  * s1 =  new struct Student;       
    delete s1; // 释放空间
}

当然我们结构体中的元素也可以一个指针


struct Student{
  int * id;
  string name;
  int age;
};

int main(){
   // 我们也可以自己分配内存使用malloc 或者new 都可以
   // new 申请了一个内存， 所以我们需要指针去接收
    struct Student  * s1 =  new struct Student;
    int id = 1;
    (*s1).id = &id;
    delete s1;

}
