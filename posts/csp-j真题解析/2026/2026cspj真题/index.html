一、单项选择题#

（共15题，每题2分，共计30分；每题有且仅有一个正确选项）

  1. 下列 C++ 数据类型中，能够精确存储 $10^{18}+1$这个整数的是（）
    A. float
    B. long long
    C. double
    D. int

答案：B
int类型的最大值为 $2^{32}-1$ 约等于 $4*10^9$
long long类型的最大值为$2^64-1$约等于 $16*10^{18}$
所以我们可以使用long long 精确存储

  1. 十六进制数 2F5 转换为八进制数是（）
    B. 1635
    C. 1405
    A. 1364
    D. 1365

答案：D
$(2F5)_{16} = 2 × 256 + 15 × 16 + 5 = 757 = (1365)_8$

  1. 执行下列 C++ 代码，输出是（ ）
int a = 7, b = 3;
std::cout << a / b * b + a % b;

A. 9
B. 10
C. 7
D. 6

答案：C
整数除法 7/3 = 2，取模 7 mod 3 = 1，所以结果为 2 × 3 + 1 = 7。

  1. 初始时栈为空，将1、2、3、4依次入栈，入栈过程中允许随时出栈。下列出栈序列中不可能出现的是（）
    A.2, 4, 3, 1
    B.1, 2, 3, 4
    C.3, 1, 2, 4
    D.1, 4, 3, 2

答案：C
1，2，3进栈，3出栈，2在栈顶，拿不到1

    A. 49

int s = 0;

8.下图为 5 × 5 网格，行号、列号均从0开始，#为障碍，.为可通行格：

S . . # .
. . . # .
. . . # .
# # . . E
. . . # .

从S出发做广度优先搜索（BFS)：初始时把S入队；每次取出队首格子，按”上、下、左、右”（上=行号减1，下=行号加1，左=列号减1，右=列号加1)的顺序遍历它的四个相邻格子，越界、障碍或已访问的格子跳过，其余格子标记为已访问并入队。当E第一次入队时，已经入队过的格子(含S和E)共有多少个()

(0, 0), (1, 0), (0, 1), (2, 0), (1, 1), (0, 2), (2, 1),

  1. 某国硬币面值为1元、4元、6元且数量不限，凑出9元最少需要多少枚（）
    A. 3

  1. 执行下列代码，输出是（）
int a[5] = {1, 3, 5, 7, 9};
int *p = a + 2;
*(p - 1) = p[0] + p[2];
p[1] = *(a + 1)  - a[0];
cout << a[1] << "," << a[3];

A. 14,13
B. 8,13
C. 14,7
D. 14,2

答案
p指向a[2]，先令a[1]=5+9=14，再令a[3]=14-1=13，输出14,13。

  1. 在含1000个互不相同元素的升序数组中，用二分法查找给定值(返回元素位置或报告不存在)，最坏情况下需要与数组元素比较多少次?()
    A. 500
    B. 9
    C. 11
    D. 10

答案：D
方法1 ： 最坏情况一定是边界边界值，我们假设查询的元素就是1总共需要
(1+1000)/2 = 500
(1+500)/2 = 250
(1+250)/2 = 125
(1+125)/2 = 63
(1+63)/2 = 32
(1+32)/2 =16
(1+16)/2= 8
(1+8)/2=4
(1+4)/2=2
(1+2)/2=1

方法2 ： 因为每一次都是2分去掉一半，我们可以考虑需要除以多少次才能让二分区间被分完即：$2^x>=1000$ 接出来x =10

  1. 数组 a[1…n] 的前缀和数组 s (即 s[i] = a[1] + a[2] + … + a[i]) 满足 s[i] = 3i² + i。则 a[10] 的值是( )
    A. 252
    B. 310
    C. 58
    D. 61

答案：C
前缀和公式： s[i] = s[i-1] + a[i]
s[10] = s[9] + a[10]
s[10] = 3100+10=310
s[9] = 381+9 =252
310 = 252 + a[i]
a[i] = 58

  1. 数轴上有7个点，坐标分别为1、3、4、7、10、15、20。在数轴上选取一个整数坐标点P，使P到这7个点的距离之和最小，这个最小距离和是()
    A. 37
    B. 42
    C. 40
    D. 38

答案： A
选择中位数7，可使距离和最小:6+4+3+0+3+8+13=37。

  1. 一个无向图有10个顶点，其中4个顶点的度为3，其余顶点的度均为4，则该图的边数是（）
    A. 36
    B. 18
    C. 17
    D. 20

二、阅读程序#

（程序输入不超过数组或字符串定义的范围；判断题正确填√，错误填×；除特殊说明外，判断题 1.5 分，选择题 3 分，共计 40 分）

(1) 二进制位统计#

#include <iostream>
using namespace std;
int main() {
  int n;
  cin >> n;
  int x = 1, y = 1;
  while (n > 0) {
  if (n % 2 == 0) {
    ++x;
  } else {
    ++x;
    ++y;
  }
  n = n / 2;
}
cout << x << ' ' << y << endl;
return 0;

以下问题均假定输入的 n 为不超过 $2^{31}-1$ 的非负整数。

程序分析：每次循环都令x加1；只有当前n为奇数时才令y加1。对n> 0,x等于二进制位数加1,y等于二进制中1的个数加1；输入0时，两者均为1。

  • 判断题

16.（1分）当输入为 3 时，程序输出为 3 3。

答案 ：T
输入3，即二进制11，共循环两次，两次均为奇数，输出33。

17.将第 11行的 ++X；删除后，程序输出的两个数一定相等。

答案：F
删除第11行后，奇数分支不再增加x。例如输入1时，输出12，两数不相等。

18.假设输入为非负整数，则程序输出的第一个数一定不小于第二个数。

答案：T
每次y加1时x也会加1，且二者初始值相同，所以始终有x≥y。

  • 选择题

19.将第 7 行的 while (n > 0) 改为 while (n >= 0) 后，程序可能出现的问题是()。
A. 陷入死循环
B. 输出结果比原来大
C. 输出结果比原来小
D. 输出结果不受影响

答案：A
n最终变为0，而0/2仍为0；条件n>=0不会变为假，形成死循环。

20.当输入为6时，输出为（）。
A. 3 3
B. 4 2
C. 4 3
D. 5 2

答案：C
输入6，二进制为110，位数为3、1的个数为2，因此输出4 3。

21.若输入 n 依次取遍 $0,1,2,...,2^{31}–1$ 中的所有整数，则程序输出的第二个数恰好为 2的次数为（）。
