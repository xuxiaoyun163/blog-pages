CCF编程等级认证四级-指针

指针与地址的概念 在讲解指针之前我们需要明白，变量到底是怎么存储在计算中的呢？ 其实一个整数存储在计算机的过程，类似我们的在菜鸟驿站存一个商品 我们在内存中会有一片连续的内存空间（快递柜），每一个空间都有唯一的一个下标（快递柜编号），计算机会随机挑选一个空的内存，将数字存放在里面（快递员将包裹存入指定的快递柜中） 例如下面这段代码，在内存中其实是放在指定的下标的柜子中 int main(){ int a ; // 找到一个空的柜子 a =100; // 将100 放入到柜子中 return 0; } 我们可以根据柜子的编号将柜子中的物品拿走，对应的代码就是我们可以根据变量名a 获取内存中存放的值。 现在突然有一天你需要陪你女朋友，没时间去拿快递，你希望隔壁老王去帮你拿一下，那你需要告诉老王快递柜的编号 在计算中，如果我们也需要进行这种操作，将快递柜的编号告诉别人怎么办呢？ 其实有的人就会认为，这个100 不就是a嘛，我直接将a告诉它不就行了。 但是在计算中，我们的地址并不会像快递编号那样，比较简单，计算机中的内存编号非常复杂，而且很长，为了方便我们每次存放和取出我们需要的值，在存放值的过程中呢，我们会将这个编号复制一份给变量名a但是这不是真正的编号，那我们该怎么去获取到当前这个变量的地址呢？ 取地址 & int main(){ int a = 10; &a; // 获取当前真正存放10的地址 cout << &a; //0xaaf69ffb9c return 0; } 我们知道地址其实一个非常长的编号&a的值可能是0x66666666但是不管这个值有多长，它始终是一个常量就是一个存在的值 现在我们拿到这个值，也就是地址，那我现在想保存这个地址该怎么办呢？ 指针 c++ 中的一种数据类型，用于存放地址 int main(){ int a = 10; int *p = &a; // 通过指针存储我们获取到的地址 cout << p; //0xaaf69ffb9c } 那现在我知道了存储的地址之后我该如何去取出这个地址中的内容呢？ 解引用 获取当前指针指向地址中的值 int main(){ int a = 10; // 定义一个变量 int* p = &a;// 获取变量的地址，并使用指针p存储 cout << *p ; //解引用，获取地址中的值 10 } 指针的经典应用 通过函数交换两个数字的值 void my_swap(int a , int b ){ int t = a; a = b; b = t; } int main(){ int a = 10; int b = 20; my_swap(a,b); // 值传递，并没有修改 cout << a << " " << b; //10 20 return 0; } void my_swap(int * a , int * b ){ // 我希望把地址穿过来，所以我使用指针去接收 // 这里的a 和 b 是地址 int t = *a; // 取出a地址中的地址 *a = *b; // 将a地址中的值 赋值为b地址中的值 *b = t; // 将b地址中的值赋值为t } int main(){ int a; int b ; my_swap(a,b); // 值传递，并没有修改 cout << a << " " << b; return 0; } 23_6_13 ...
