安装NeoVim 下载 Releases · neovim/neovim 官方提供了2中安装方式，一种是zip，一种是msi这里我们使用zip的安装方式 我们可以在Assets中找到安装包，并下载 安装 我们将下载好的nvim-win64.zip 解压缩要合适的目录，我这里解压到D:\apps\nvim-win64 解压完成之后我们需要配置环境变量 我们找到nvim.exe 所在目录，将这个目录配置在path中 PS： 如果不会配置环境变量，请百度搜索 配置完环境变量之后我们打开powershell输入nvim -version 我们已经成功安装neovim了 三种模式 normal model 当我们使用nvim hello_vim.txt 打开文件时，默认就是normal model模式 光标操作 一般在normal model 下我们会进行光标操作 h: 向左 j: 向上 k: 向下 l: 向右 100j: 向上移动100行 gg: 跳转到第一行 G : 跳转到最后一行 insert model 在 normal mode 下我们按下 i 键 可以进入 insert model模式，可以输入文本 在输入完成之后我们可以按下esc 退出 insert model 进入normal model模式 command-line model 在normal model 模式下 按下 : 可以进入命令模式 ...
